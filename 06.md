# ORE-06

## The `/stats` Endpoint

`draft` `optional`

This document defines the `/stats` endpoint, which returns a rank and a set of statistics for a single Nostr pubkey. It is the single-pubkey counterpart to `/rank`, returning the same rank alongside richer data about the identity.

---

## Endpoint

```
POST /stats
```

Returns a rank and statistics for the given pubkey according to the requested algorithm.

## Request

| Field | Type | Required | Description |
|---|---|---|---|
| `pubkey` | string | yes | The pubkey to retrieve statistics for. MUST follow the format defined in [ORE-00](00.md). |
| `algorithm` | string | no | The algorithm to use. If omitted, the provider MUST use the default algorithm for this endpoint as defined in [ORE-01](01.md). |
| `pov` | string | no | A point-of-view pubkey for personalised algorithms. MUST be provided if the requested algorithm requires it, as declared in the capability document. |

### Example Request

```json
{
  "pubkey": "a3f9c...",
  "algorithm": "wot-rank",
  "pov": "b7e2d..."
}
```

## Response

The response is a JSON object. `pubkey` and `rank` are always present. All other fields are optional and MAY be omitted by the provider depending on available data.

| Field | Type | Required | Description |
|---|---|---|---|
| `pubkey` | string | yes | The pubkey that was queried, as provided in the request. |
| `rank` | number | yes | The rank assigned to this identity by the requested algorithm. Higher values are always better. The scale and range are defined by the algorithm. |
| `followers` | integer | no | Number of followers in the provider's indexed follower set. |
| `following` | integer | no | Number of pubkeys this identity follows, as known to the provider. |
| `muters` | integer | no | Number of pubkeys that have muted this identity. |
| `mutes` | integer | no | Number of pubkeys this identity has muted. |
| `reports` | integer | no | Number of reports received by this identity. |
| `posts` | integer | no | Number of kind-1 notes published by this identity. |
| `replies` | integer | no | Number of kind-1 replies published by this identity. |
| `reactions` | integer | no | Number of kind-7 reactions received by this identity. |
| `reposts` | integer | no | Number of kind-6 reposts received by this identity. |
| `first_seen_at` | integer | no | Unix timestamp of the first activity by this identity seen by the provider. |
| `ttl` | integer | no | A hint indicating how many seconds the response is expected to remain valid. Clients MAY cache the result for this duration. Clients MUST treat this value as a hint, not a guarantee. |

Providers MAY include additional integer fields beyond those listed below. Clients MUST ignore unrecognised fields.

### Example Response

```json
{
  "pubkey": "a3f9c...",
  "rank": 0.91,
  "followers": 1400,
  "following": 320,
  "muters": 12,
  "mutes": 5,
  "reports": 0,
  "posts": 8741,
  "replies": 2310,
  "reactions": 4502,
  "reposts": 871,
  "first_seen_at": 1673000000,
  "ttl": 3600
}
```

## Errors

Algorithm selection and pov validation follow the rules defined in [ORE-01](01.md).

| Status | Reason |
|---|---|
| `400` | The request body is malformed or not valid JSON. |
| `422` | The `pubkey` field is missing or invalid. |
| `422` | The requested algorithm is not supported by this endpoint. |
| `422` | The requested algorithm requires a `pov` but none was provided. |
